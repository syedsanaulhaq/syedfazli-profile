Data Safety

App: HO Weather Map

This summary supports the Play Console Data Safety form and should be reviewed each release.

Data Types Collected

  • Location: Precise location (while app is in use)
  • Personal info: Name, email address, country/region (if user registers)
  • Diagnostics: Device model, OS version, app performance logs

Purpose of Collection

  • Map weather and hazard data against user location.
  • Enable account and Traveler Community features.
  • Improve reliability, monitor crashes, and fix issues.

Sharing and Sales

  • Data sold: No
  • Shared with third parties: Only with service providers required to operate the app (for example Google Play Services/Firebase).
